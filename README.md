# 🌾 FarmDelve

A single-player farming game with tiered dungeons and gear upgrading!

## 🚧 Status

In development — early design stage.

## 🎯 What we plan to design

- ⚔️ Real-time combat
- 🗡️ Three weapon specializations — Sickle, Crossbow, Watering Can
- 🏰 Dungeon tiers
- 🔨 Gear upgrading
- 🏆 Leaderboard

## 🧱 Planned stack

React · Node.js/Express · PostgreSQL
